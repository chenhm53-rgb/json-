# Cookie JSON 工作台当前改动说明

更新时间：2026-09-09

## 2026-09-09：改为真实积分接口检测

- 修正原先只读取 JSON 显式积分字段、不能按 Cookie 验证真实积分的问题。
- `credit_stats_scraper.py` 现在逐条把记录中的 Cookie 放入积分接口的 `Cookie` 请求头。
- 支持 GET / POST、`{identifier}` / `{index}` / `{cookie}` 模板、POST 请求体、积分 JSON 路径、请求间隔和自动重试。
- 支持网页导出 `credit_api_config.json`，脚本可用 `--config` 直接读取。
- 输出接口检测明细 JSON/CSV 和积分汇总 JSON/CSV；汇总按积分从低到高统计数量。
- 结果文件不保存 Cookie 原文，失败项只记录序号、标识符、HTTP 状态和错误原因。
- 网页明确提示静态页面受 CORS 与 Cookie 请求头限制，避免把无法工作的浏览器端按钮当成已完成检测。
- 修复 `{cookie}` URL 占位符被错误替换为空字符串的问题；增加 Cookie 对象格式和超时配置兼容。
- 已将 Adobe 接口 `GET https://firefly.adobe.io/v1/credits/balance` 写入默认配置；积分字段留空时自动识别，避免猜错返回结构。

## 本次改动

### 7. 新增网页积分抓取与统计工具

- 新增 `work/src/credit_stats_scraper.py`，用于读取 JSON 记录并按 URL 规律逐条打开网页。
- 支持从网页 CSS 选择器读取积分数字。
- 支持 JSON 中的 `cookie`、`cookie_string`、`cookie_header` 和 `cookies` 数组作为浏览器会话信息。
- 支持需要登录的情况：打开可见浏览器，手动登录后按回车继续抓取。
- 输出抓取明细 JSON/CSV，以及按积分从低到高排序的汇总 JSON/CSV。
- 新增 `work/src/积分统计抓取说明.md`，包含参数配置、Python/Playwright 安装、运行和报错反馈步骤。

网页工作台也新增“积分额度统计”区：

- 只识别明确命名的 `credit`、`points`、`balance`、`quota`、`amount`、`积分`、`额度`、`余额` 等数值字段。
- 支持 JSON/CSV/TSV 的积分字段。
- 统计会跟随搜索和来源筛选更新，并支持单独导出统计 JSON/CSV。
- 对只有认证字段的 Cookie 文件显示“未识别”，不会把 `ftrset`、时间戳或 token 内数字误判为积分。

对 `credits_4000-15000_222.txt` 的检查结论：文件有 222 条 Cookie，但没有明确积分字段；文件名范围不能可靠地分配到每条 Cookie，因此页面会显示 222 条未识别，并提示原因。

### 1. 修复常规 cookie 文本导入

- 修复了 `.txt` 一行一个 cookie 的识别问题。
- 现在可正确识别并生成 200 条 cookie 的 JSON。
- `Cookie:` 请求头、纯 cookie 字符串、Netscape 格式都能继续正常处理。
- 每个导入来源支持单独导出，不再只能导出全部记录。

### 2. 新增本地数据库

- 新增浏览器本地保存功能。
- 可把当前导入结果保存到 IndexedDB。
- 支持重新打开、删除、导出单个保存集。
- 支持导入和导出整个数据库备份。

### 3. 新增账户 JSON 适配

- 新增对 `accounts[]` 结构的支持。
- 适配类似 `cookies_credits_ge500.json` 这种文件。
- 每个账户会提取 `cookie` 作为输出内容。
- 默认仍输出 `id / name / cookie`。
- `name` 优先使用 `email`，再用 `display_name`，最后用 `account_id`。

### 4. 新增逐行 JSON 适配

- 新增对 JSON Lines / NDJSON 的支持。
- 适配类似 `卡密导出_20260902.txt` 这种文件。
- 文件里每一行可以是一个独立 JSON 对象，例如 `{"cookie":"..."}`。
- 即使文件扩展名是 `.txt`，也会自动逐行解析 JSON 并提取 `cookie`。

### 5. 保留附加信息

当开启附加元数据时，会额外输出：

- `source`
- `format`
- `domain`
- `cookieCount`
- `accountId`
- `email`
- `displayName`
- `creditsAvailable`
- `creditsTotal`
- `creditsUsed`
- `creditsAvailableUntil`

### 6. 新增批量校验与分割

- 新增独立的“批量校验与分割”面板。
- 分割功能拥有独立文件导入框，支持点击选择和拖拽导入。
- 进入分割区的文件只用于校验与拆分，不会自动混入上方转换结果。
- 支持一次选择多个文件，逐个检查是否适配当前系统导入格式。
- 校验通过的文件会显示“可导入”，不适配或读取失败的文件会显示“不适配”。
- 支持设置“每份记录数”，把大量记录拆成多份 JSON。
- 支持单个分片导出，也支持“导出所有分片”。
- 支持把校验通过的文件一键加入当前转换结果。

## 适用文件

- HAR 文件
- CSV / TSV
- Netscape cookie 文件
- `accounts[]` 账户 JSON
- 逐行 JSON / NDJSON 文本
