## 变更范围

- 主页面标题和品牌名改为“工作台”。
- 删除顶部邮箱工作台链接及“纯前端运行、数据不上传、单文件可部署”等说明。
- 隐藏侧边栏“数据管理”和对应界面，但保留浏览器 IndexedDB 代码。
- 主导入、批量分割、AS 两个文件区和邮箱工作台支持任意扩展名文件拖入。
- 增加 `workbench_backend.py`，提供标准库 Python API、AS 转换和 SQLite 数据库仓储接口。
