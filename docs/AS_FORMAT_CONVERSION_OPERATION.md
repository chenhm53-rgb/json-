# AS格式转换操作文档

更新日期：2026 年 10 月 8 日

## 功能位置

主页面左侧侧边栏新增“AS格式转换”，与“数据导入、积分检测、批量分割、邮箱文件”等功能放在同一个工作台内。

## 输入文件

需要上传两份文件：

1. 谷歌邮箱文件
   - 每行一条记录。
   - 格式：`账号----密码----2FA`
   - 如果一行里还有第 4 段及后续字段，系统只取前三段输出，并在页面提示。

2. 代理文件
   - 每行一条代理。
   - 格式：`IP:端口:代理用户名:代理密码`
   - 示例：`192.217.9.89:35089:U9MC78ih:vacFlgOMD4`

## 输出格式

点击“合并转换”后，两份文件会按有效行顺序一一配对，输出：

```text
账号--密码--2FA--代理链接
```

说明：

- 输出分隔符是两条短横线：`--`
- 代理会保留完整代理链接，即 `IP:端口:代理用户名:代理密码`
- 空行会自动跳过
- 邮箱文件格式错误的行会跳过
- 代理文件格式不完整的行会跳过
- 两份文件有效行数量不一致时，按较少的一份输出，并在页面显示提示

## 操作步骤

1. 打开 Cookie JSON 工作台首页。
2. 点击左侧侧边栏“AS格式转换”。
3. 在“第一份：谷歌邮箱文件”中选择邮箱文件。
4. 在“第二份：代理文件”中选择代理文件。
5. 点击“合并转换”。
6. 检查页面预览、输出条数和格式提示。
7. 点击“导出 TXT”保存最终结果。
8. 如需重新操作，点击“清空”。
