# Cookie 积分接口检测工具说明

这个工具会读取系统导出的 JSON，逐条把每个 Cookie 放进积分接口的 `Cookie` 请求头，获取接口返回的积分，然后统计每个积分值有多少条记录。

## 重要前提

必须知道真实的积分接口信息。仅凭 Cookie 文件、文件名中的数字范围或 token 内容，无法可靠推断积分。

你已提供的 Adobe 积分接口：

```text
GET https://firefly.adobe.io/v1/credits/balance
```

需要准备：

- 积分接口地址：`https://firefly.adobe.io/v1/credits/balance`
- 请求方式：GET 或 POST
- 接口返回 JSON 示例
- 积分字段路径，例如 `data.credits`、`data.balance`
- 如果返回 401/403，可能还需要从浏览器该接口请求中复制额外请求头，例如 `Authorization`、`x-api-key` 或组织标识；只在自己的本地配置中填写，不要发到聊天里。

接口 URL、POST 请求体和标识字段支持 `{identifier}`、`{index}`、`{cookie}` 占位符。默认方式是把当前记录的 Cookie 放在请求头中；只有接口明确要求时，才把 `{cookie}` 放进 URL 或请求体。

不要把完整 Cookie、密码、验证码或额外 token 发给别人。只对你有权限访问的网站和数据使用本工具。

## 一、准备输入 JSON

网页工作台导出的标准格式如下：

```json
[
  {"id":"1","name":"cookie_1","cookie":"session=脱敏值; other=脱敏值"},
  {"id":"2","name":"cookie_2","cookie":"session=脱敏值; other=脱敏值"}
]
```

脚本也会自动识别 `cookie`、`cookie_string`、`cookie_header`、`Cookie`、`cookies` 等常见字段，并自动识别 `id`、`cookie_id`、`account_id`、`uid`、`email` 等标识字段。

## 二、从网页导出配置

1. 打开 `index.html`。
2. 导入 Cookie JSON 文件。
3. 在“积分接口检测配置”填写真实接口 URL。
4. 选择 GET 或 POST。
5. 返回积分字段路径可以先留空，脚本会自动识别 `credits`、`balance`、`available`、`quota` 等明确字段；如果返回多个候选字段，再根据接口返回 JSON 填写准确路径。
6. 如果 Adobe 接口需要额外请求头，在“额外请求头 JSON”中填写对象，例如 `{"Authorization":"Bearer 你的值"}`。
6. 如果自动识别字段不准确，再填写 Cookie 字段名和标识字段名。
7. POST 接口需要请求体时，填写模板，例如 `{"account_id":"{identifier}"}`。
8. 点击“导出接口配置”，得到 `credit_api_config.json`。

接口返回示例：

```json
{"data":{"credits":500}}
```

对应路径就是：

```text
data.credits
```

## 三、安装 Python

### macOS

```bash
python3 --version
```

如果没有 Python 3，请从 [Python 官网](https://www.python.org/downloads/) 安装。然后进入工具目录：

```bash
cd "/Users/admin/Documents/Codex/2026-08-24/11/work/src"
```

### Windows

安装 Python 时勾选 `Add Python to PATH`，然后在 PowerShell 进入脚本目录：

```powershell
cd "C:\data\cookie-tool"
```

本脚本只使用 Python 标准库，不需要安装第三方包。

## 四、运行检测

把下面文件放到同一目录：

- `credit_stats_scraper.py`
- `credit_api_config.json`
- 要检测的 Cookie JSON，例如 `cookies.json`

不要直接把 `credit_api_config.example.json` 当成真实配置运行，必须先把示例接口地址和积分字段改成实际值。

macOS：

```bash
python3 credit_stats_scraper.py --config credit_api_config.json --input cookies.json
```

Windows：

```powershell
python credit_stats_scraper.py --config credit_api_config.json --input cookies.json
```

也可以直接修改脚本顶部的配置，或不用配置文件：

```bash
python3 credit_stats_scraper.py \
  --input cookies.json \
  --url "https://你的域名/api/user/credits" \
  --method GET \
  --points-path "data.credits"
```

脚本默认每条请求间隔 0.3 秒，失败自动重试 2 次。接口限制严格时，可以在网页中把间隔调大。

## 五、输出文件

默认输出到 `credit_api_output`：

- `接口检测明细.json`：每条记录的成功/失败、积分、HTTP 状态和错误
- `接口检测明细.csv`：方便用表格软件查看
- `积分接口汇总.json`：总数、成功数、失败数、最低/最高/平均积分及分组
- `积分接口汇总.csv`：按积分从低到高的数量表

示例：

```text
积分,数量
100,3
200,5
500,2
```

脚本结果文件不会写入 Cookie 原文。

## 六、常见问题

### 全部返回 HTTP 401 / 403

通常是 Cookie 过期、接口还需要额外请求头，或当前账号没有权限。检查浏览器开发者工具中该接口的请求，但不要把完整 Cookie 粘贴给别人。

### 找不到积分字段

把接口返回 JSON 中的积分字段路径填写准确，例如 `data.balance`、`user.credit`。数组路径可以写成 `data.0.credits`。

### 返回不是 JSON

说明请求可能被重定向到登录页、接口地址不对，或接口返回 HTML。先检查 URL、Cookie 是否有效以及接口响应内容类型。

### 如何反馈错误

请复制终端中的错误文字、接口返回状态码、脱敏后的 JSON 结构和 `积分接口汇总.csv`。隐藏 Cookie 值、密码、验证码和 token，只保留字段名与错误信息。
