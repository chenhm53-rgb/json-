# 工作台小白说明书

更新日期：2026 年 10 月 8 日

## 你现在看到的是什么

网站标题已经改成“工作台”。主页面左侧是功能入口，右侧是当前功能的操作区域。截图中的顶部说明已经删除，左上角也不再放邮箱文件工作台链接。

## 导入文件

1. 点击左侧“数据导入”。
2. 把文件直接拖到“导入文件”框，或者点击框选择文件。
3. 现在不要求文件扩展名必须是 `.txt`、`.json` 等。可以拖入任意扩展名，工作台会根据内容尝试识别。
4. 识别后，点击“统计结果”查看数据，再从顶部按钮下载 JSON、CSV 或 TXT。

## 邮箱合并、凑整、分割

点击左侧“邮箱文件”。邮箱文件可以直接拖入页面。合并后可以按目标数量凑整，也可以设置每个小文件的行数，再点击“开始分割”。分割会保留原始顺序，之后可以单独下载或下载全部分片。

## AS 格式转换

点击左侧“AS格式转换”，分别把两份文件拖入两个框：

- 第一份：`账号----密码----2FA`
- 第二份：`IP:端口:用户名:密码`

点击“合并转换”，结果会是：

```text
账号--密码--2FA--IP:端口:用户名:密码
```

点击“导出 TXT”保存结果。两份文件有效行数不一样时，系统会按较少的一份配对，并在页面提示。

## 为什么看不到“数据管理”

这是按本次需求暂时隐藏的界面，不是删除功能。数据库相关代码仍保留，浏览器端仍使用 IndexedDB；另外还提供了 Python SQLite 接口，方便以后接入真正的数据库服务。

## 启动 Python 接口

如果只想使用页面，不需要启动 Python。需要持久化 SQLite 数据库时打开终端，进入本说明书所在项目目录，运行：

```bash
python3 workbench_backend.py
```

看到 `工作台 Python 接口已启动` 就表示接口启动成功。关闭接口可以在终端按 `Ctrl+C`。

## 常见问题

- 拖不进去：把文件拖到有虚线边框的区域，看到区域高亮后松手。
- 文件识别不到：检查文件内容是否每行一条记录；页面会显示格式提示。
- 浏览器没有自动下载多个分片：按浏览器提示允许多个下载。
- 页面打不开：在项目目录运行 `python3 -m http.server 8000`，然后打开 `http://127.0.0.1:8000/`。
- 微信临时文件提示无法读取：这是 macOS 对微信容器临时目录的保护。请在微信里先选择“另存为”，保存到桌面或“下载”文件夹，再把保存后的文件拖进工作台。
