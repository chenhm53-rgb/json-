# 最新安装包说明

本目录用于存放当前发布版安装包。

- `deploy-cookie-json-workbench.zip`：完整 GitHub Pages / Vercel / Netlify 部署包。
- `cookie_json_workbench_github.zip`：Cookie JSON 工具网页部署包。
- `cookie_json_workbench_api.zip`：包含积分统计脚本与接口配置示例的工具包。
- `积分统计抓取工具.zip`：积分统计抓取功能独立包。
- `收银王_cookie失效恢复功能.zip`：收银王 Cookie 失效恢复独立功能包。

注意：公开仓库不要上传真实 Cookie、API Key、密码或 Token。收银王恢复功能的 API Key 需要在本机代理里通过环境变量配置。
